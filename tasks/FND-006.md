# FND-006 — Operational Reproducibility and Agent-Governance Contract

**Owner:** Overseer
**Dependencies:** CTRL-004 (validated)
**Capability weight:** 0.5 points
**Acceptance state:** ready until separately reviewed
**Write scope:** governance docs, `schemas/`, `tests/governance/`, `tools/governance_contract.py`, and governance CI workflow.

## Objective

Make the repository's agent handoff, evidence requirements, reproducibility and CI enforcement **testable rather than aspirational**, without requiring a completed dashboard, model checkpoint or approved third-party data.

## Operational acceptance

1. Canonical state/weighted progress and task dependencies are enforced by existing `projectctl`.
2. Every task handoff/evidence bundle has a machine-validatable required-information contract, including branch, SHA, actual changed-file list, tests and their outcomes, acceptance checklist, licensing/provenance assessment and unresolved risks.
3. Task-branch scope violations can be detected from a changed-file manifest and canonical task brief scopes, without silently assuming an agent's claimed files are the whole diff.
4. Experiment records have a strict versioned schema: no result is considered validated unless code/data/split/model/config/environment/metrics/artifact provenance exist.
5. CI checks canonical state, **all existing Python test domains**, source registry and new governance controls, not just the original projectctl test subset.
6. Synthetic positive/negative fixtures exercise these checks. No external raw manuscript or benchmark assets are ingested.
7. Document limits honestly: a local scope check is not a signed GitHub PR approval; a populated evidence bundle is not proof a command was run; dataset license permission needs human review.
8. Overseer acceptance must be recorded separately from the implementation PR. Only then award 0.5 points.

## Explicit non-goals

- Deploying or accepting CTRL-003 dashboard.
- Running or validating any model experiments.
- Automatically approving third-party image licenses or raw asset acquisition.
- Relabeling revision-required agent tasks.
