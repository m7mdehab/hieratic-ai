## Completed original-source execution — W24 2026-10-10

**Exact original real-data run:** [hosted GitHub source evidence 38006184794](https://github.com/m7mdehab/hieratic-ai/actions/runs/38006184794), full deterministic [R029 verified results](R029_DDD_REAL_ANNOTATION_BASELINE_RECEIPTS.json). The script pinned all 3 actual Zenodo original sources to publisher MD5 and local SHA256: `papyri.json` (56,679 bytes), `classes.json` (203,550 bytes), and `samples.json` (12,113,887 bytes). No source images, 416 MB split ZIP, annotations' original records, or commercially restricted raw assets were checked into Git.

**Real public scholarly annotation experiment (not a visual reading experiment):** 17,885 sign/group sample annotations belonging to 159 photographed records and **50 independent papyrus document clusters**. Fixed deterministic source-witness holdout: **35 training physical manuscripts, 7 development, 8 test**; 15,426/893/1,566 annotation examples. **Zero original-document intersections**. Training classes 490, test classes 219; 10 test-only classes unseen in training. **1,555/1,566 test annotations are of labels attested somewhere in training**; category availability alone cannot guarantee visual generalization. The historically sensitive `003` + `004` Cat1880 transformed-view images are one physical source; fixed split assigns both to train.

**Methodological control:** a naive *sample-random* 70:15:15 split would place records from **49 of 50 original physical manuscripts in more than one partition**. This demonstrates source overlap danger without opening an official sealed benchmark or drawing imaginary training results.

**Nonvisual negative-control result:** fit only the *most frequent training publisher class label*; predict that one class for every test example. Correct **81/1,566**, or **5.172414%**. This is **NOT image-based Hieratic recognition**: neither image pixels, embeddings, model inference nor human-independent held-out paleographic gold were used. It is a prerequisite trivial baseline that any future image-based model should outperform, but no model score is yet accepted.

**Dataset scientific scope:** DDD annotations are publisher-scholarly, not two independent project-blind adjudicators. Copyright records comprise **48 distinct per-item claims** and include unverified entries; DDD aggregate license **CC BY-NC-SA 4.0**.
