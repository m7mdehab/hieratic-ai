## Predeclared cohort rule (no selecting by outcome)
1. Load the publisher's original complete `bbawarchive` JSON **only after this registration commit exists**. Verify exact upstream Git blob SHA-1 and source byte size. Reject a mismatch.
2. Require original AES schema: dictionary of sentence IDs, each row `text` (source text ID), `token` list of nonempty Egyptian `written_form`, and `sentence_translation` string; missing German reference is an unscorable row, not a silently dropped source record.
3. Group by original `text` identifier. **Reject** any overlap with ALL four existing W9 AES subcorpora (418 published text IDs), not merely training; do not suppress overlaps by filtering them out.
4. Select exactly **32 entire source-text groups**, ranked ascending by SHA-256(`b"hieratic-ai-ling003-w10-archive-v1:" + text_id.encode("utf-8")`), tie-break lexicographically by text ID. If fewer than 32 distinct groups, refuse to score. Do not choose based on number or content of German translations, period, names or apparent model fitness. Publish all 32 selected identifiers' hashes and aggregate source counts; keep sentence texts or publisher outputs in CC BY-SA paths only.
5. Compare predictions on *all* selected group sentences with German publisher references, count missing targets and abstentions. No training, n-gram statistics, glossary creation, hyperparameter selection, feature design, prompt selection or post-hoc retuning may use **any** archive sentences, including the 32 chosen groups **or the other unselected archive rows**.

## Frozen model/evaluation protocol
- Fit only on the **904 translated** W9 internal developer-source AES sentences from `bbawfelsinschriften`, `smaek`, `bbawgraeberspzt`; never use previously exposed Tübingen refs or any archive text during fitting/tuning.
- Three compared systems on identical external records: (A) other-source Egyptian-form → most-attested German word-cotext *gloss fallback*, (B) original W9 TF-IDF German **whole-sentence retrieval** with **previously selected threshold 0.0** frozen, (C) a new bounded compositional source-token unit method using train-only lexical alternatives, neighboring Egyptian source forms for sense selection and disjoint adjacent-unit inversion **only with at least 2 independent train source-text witnesses** and a >2:1 inversion/normal ratio. No full source sentence/German reference copying as a production path for C.
- Fixed compositional decision parameters: max 12 alternate glosses per token, context sense evidence >=2 independent train text IDs, pairwise reorder evidence >=2 independent train text IDs and reverse votes >2*forward votes; no neural training, no paid inference, no adding unsupported German function words. Unknown forms produce explicit `[?]` abstention; no guessing of grammatical roles from publisher reference. No tuning grid or selection on new external set.
- Internal sanity preflight: 5 fixed SHA-256(text_id) grouped folds on same 904 training/dev sentences; no use of Tübingen or archive rows. Inspect internal behavior before unblinding archive, but do not change locked parameters to maximize publisher German overlap.
- Full-population group-aware audit: exact counts (selected text IDs, translated/scored sentences, unknown tokens), macro and micro German word-overlap F1, mean char ngram F2 as **in-house diagnostic** (not BLEU), mode counts, copies of nonidentical train-source full German sentences (expected ZERO for C, except accidental equivalent wording explicitly audited), substitutions/abstentions, traceable chosen lexical sources and German word-order evidence.
- **No expert semantic adequacy claim** or LING-003 points; evidence cannot certify grammar accuracy, physical-witness independence, licensed photographed original readings, or model-pretraining independence.

If implementation must deviate from this preregistered protocol, file a **new version before** further external test inspection and mark previous cohort as exposed.
