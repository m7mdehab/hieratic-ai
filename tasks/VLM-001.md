## 1. Mission and Scientific Objectives

Establish a scientifically reproducible, untuned zero-shot and few-shot Vision-Language Model (VLM) baseline suite for Hieratic script reading across multiple task rungs (`identify`, `signs`, `transliterate`, `translate`).

This task operates independently from the overseer's `EVAL-003` frontier proprietary model comparison (`eval/baselines/**`), focusing on open-weight multimodal architectures, formal prompt contracts, quarantined few-shot demonstration banks, complete attempt accounting, and standardized evaluation protocols.

---

## 2. Core Scientific Requirements

1. **Immutable Evaluation Conditions:**
   - Pre-register exact model identifiers, revisions, decoding parameters (greedy sampling `temperature=0.0`, fixed random seed, deterministic stop sequences), and standardized image preprocessing (resolution constraints, aspect ratio preservation, color channel normalization).
   - Freeze zero-shot and few-shot prompt templates with cryptographic hashes (SHA-256).

2. **HieraticBench Quarantine and Zero-Leakage Demonstration Bank:**
   - HieraticBench items remain strictly evaluation-only. No public benchmark examples or near-duplicates may be used as few-shot demonstrations, prompt optimization examples, or development training data.
   - Few-shot demonstrations are sourced exclusively from independently licensed, non-overlapping external collections (`OPEN-PD`, `CC0-1.0`, or permissively cleared synthetic facsimiles) with verified zero overlap against benchmark or sealed evaluation partitions.

3. **Mandatory Image Conditioning:**
   - The adapter framework strictly enforces multimodal image ingestion. Text-only shortcuts, unconditioned guessing, or hardcoded mock answers that bypass image input fail closed.

4. **Complete Attempt Preservation (No Cherry-Picking):**
   - Every evaluation attempt is immutably recorded in the run manifest, including successful responses, execution errors, inference timeouts, explicit abstentions, and safety refusals.
   - Dropping failed samples or cherry-picking runs is strictly prohibited by schema and auditor validation.

5. **Multi-Rung Metrics and Uncertainty Reporting:**
   - Score rungs using official task-level metrics aligned with `eval/metric_contract.yaml` (script accuracy, Character Error Rate, Word Error Rate, BLEU-4, chrF++).
   - Report explicit coverage rates and selective risk alongside accuracy.
   - Calculate non-parametric bootstrap confidence intervals (95% CI) and report document-level grouping uncertainties.

6. **Paired Comparisons:**
   - Maintain stable item keys across models and shot regimes to support rigorous paired difference statistics (paired bootstrap differences, win/loss/tie matrices, McNemar testing).

7. **Zero Paid API Inference Gate:**
   - Fails closed against unapproved paid external API calls (`max_paid_spend_usd = 0.0`). All automated CI and local preflight checks use deterministic mock or local offline execution.

## 4. Boundary and Deployment Notice

Validation of this harness certifies the **reproducible evaluation framework, schema contracts, leakage controls, and offline test infrastructure**. Live evaluation runs against heavy open-weight models (e.g., Qwen2.5-VL-7B, Pixtral-12B) require dedicated local GPU acceleration (NVIDIA CUDA with >= 16 GB VRAM) and downloaded model weights. In their absence, the harness accurately records local hardware unavailability without generating falsified model scores.
