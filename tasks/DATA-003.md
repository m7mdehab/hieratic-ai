# DATA-003 — Reproducible Preprocessing and Dataset Versioning

Implement deterministic transforms for rights-cleared, provenance-identified assets. Inputs require an acquisition-manifest reference, rights clearance and a completed benchmark-overlap review. Evaluation-only, quarantined, unknown-rights, incomplete, and unidentified inputs fail closed. Record input/output SHA-256, transform configuration, lineage and software version. Version IDs derive from canonicalized inputs, configuration and outputs. Image operations declare orientation, mode, crop bounds, coordinate mapping and resize policy. Text normalization is profile-driven and versioned. Tests use synthetic repository-authored fixtures only; do not fetch or incorporate manuscript images or benchmark answers. Do not change canonical project state or task status.
