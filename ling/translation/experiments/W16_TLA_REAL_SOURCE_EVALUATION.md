# W16 original-publisher Late Egyptian text scoring
The earlier W15 algorithm was preregistered at commit 319f7baf3bf15df0b29c9d79053f311648bc9a19 before full target retrieval. This overseer-only hosted workflow attempts execution, not hypothetical infrastructure. It pulls the public TLA Late Egyptian premium version-locked train.jsonl (3,606 rows; CC BY-SA 4.0), verifies original publisher Git-blob identity and SHA-256 with a hard 8MB limit, and executes the W15 fixed AES train-only inference and F1 scorer against all original target sentences. It outputs only aggregate numeric metrics, source digests and an integrity/claim report, not original downloaded sentences. Raw publisher file stays in temporary runner directory and is unlinked after scoring.

The official TLA release has no source-object IDs in its eight export columns. This result CANNOT establish physical-witness split independence, manuscript image reading, certified fluent German semantic adequacy or LING-003 milestone. AES/TLA editorial genealogy is unresolved. No benchmark-protected answers, unlicensed manuscript images, third-party correspondence, paid model API, adaptive tuning or project progress change is authorized. Any network/source mismatch refuses scoring rather than substituting a sample. GitHub Actions standard hosted usage is governed by repository settings, not a claim that inference cost is zero.
