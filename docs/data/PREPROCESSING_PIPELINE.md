# Deterministic preprocessing pipeline

`tools.preprocessing` validates a request against `schemas/preprocessing_manifest.schema.json`, the DATA-001 source registry and the acquired source bytes before writing artifacts. The standard-library decoder accepts 8-bit non-interlaced PNG (grayscale, RGB, RGBA) and P3/P6 PPM. PNG palette, interlaced, non-8-bit and other formats (including JPEG/TIFF) are refused; no undeclared image package is required. A real item must reference a completed DATA-002 acquisition record, identify a source object, match the input SHA-256, use an eligible rights decision, and have benchmark quarantine/overlap explicitly clear. Unknown, evaluation-only, quarantined, or conditional/unapproved source decisions fail closed. `synthetic:` records under `SRC-REPO-SYNTHETIC` are a narrowly scoped repository-fixture exception for tests and examples; they are not claims of third-party clearance.

## CLI

`python -m tools.preprocessing validate MANIFEST.yaml --acquisition DATA002.yaml` is dry-run and writes nothing. `python -m tools.preprocessing run MANIFEST.yaml --acquisition DATA002.yaml --output DIR` writes canonical PNG artifacts and `dataset-manifest.json`. Real items must match exactly one completed DATA-002 source/object record, match its acquired SHA-256 and logical fingerprint, pass DATA-002 policy validation, use an allowed source decision, and carry a clear overlap review. The DATA-002 manifest ID and item fingerprint become output lineage. The only no-acquisition exception is the explicit `synthetic:` fixture namespace. PNG encoding uses uncompressed DEFLATE blocks for compressor-version-independent bytes, and output omits source metadata. The dataset version hashes sorted input/output lineage, acquisition manifest ID, profile ID, and generator output metadata; timestamps are excluded. Crop bounds are `[left, top, right, bottom]` in the current decoded image's `pixel_origin_top_left` coordinates, with right/bottom exclusive. Resize supports explicit contain/cover/exact and nearest/bilinear resampling; contain centers on a zero-valued mode-appropriate canvas, cover centers the crop, and exact changes aspect ratio. Rotation is explicit (`identity`, clockwise 90/180/270); metadata orientation is not inferred. Mode conversion supports `L`, `RGB`, and `RGBA`, with integer BT.601-style luma conversion and opaque alpha when converting RGB. Crop, resize and rotation record cumulative input-to-output affine coordinate matrices. Unsupported operations fail.

Text changes are opt-in profiles with profile ID and version. `identity/1.0.0` is byte-for-character identity; `unicode-nfc/1.0.0` applies Unicode NFC only. Neither profile interprets, transliterates, expands, nor resolves scholarly readings. The original `text_input` is retained in the manifest and the output records its normalized form.

## Future authorized sources

For each future real asset, first acquire and hash through DATA-002, verify DATA-001 source/item rights and all conditional terms independently, record exact item provenance and an overlap review, then reference those immutable records here. Conditional or unknown rights are not made eligible by fields in this manifest. Store large artifacts outside Git where policy requires; never fetch benchmark material or use this pipeline to make it train/dev eligible. The included PPM fixture is synthetic and exists only to test deterministic encoding.
