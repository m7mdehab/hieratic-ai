## Frozen empirical question
How does a **fully train-only** deterministic German contextual gloss retrieval method built on previously published *AES* editorial corpora transfer to *new published TLA Late Egyptian* transliteration (not image-derived text) and German editorial sentence references, compared to a no-evidence abstention baseline? This diagnoses lexical transfer and period/normalization failure, not fluent translation or semantic adequacy.

- **Training/index**: only pinned W11 original AES donor 3,021 sentences, keyed by exact Unicode-casefolded token `written_form`. Each German `cotext_translation` is an attested candidate, counted at most once per `text` publisher source group per (form, gloss); choose highest number of distinct train text groups with lexicographic tie break. No target form gloss, morphology, lemma, POS or German translation used to build index.
- **Prediction input**: target `transliteration` split on Unicode whitespace into written units, use casefold only to align with AES `written_form` values. One German contextual gloss per exact matched form; unmatched unit is `[?]` with explicit abstention. Preserve original input as given and never silently transliterate or align by hidden target `lemmatization` or `glossing`.
- **Second fully frozen mechanism**: If and only if the **entire exact normalized ordered target transliteration-token sequence** equals a donor AES sentence's sequence, return a German **publisher sentence_translation** drawn from a different (training) publisher text, chosen by highest support in distinct donor text groups, tie lexical. Otherwise return the gloss sequence. Report exact-parallel cases separately. No approximate retrieval tuning after viewing target.
- **Scoring**: generate every target prediction in one pass **before consulting any target reference**. Then use target `translation` only in the scorer. Evaluate all 3,606 rows (no skipping difficult ones) with normalized casefold punctuation-removed German multiset word overlap precision/recall/F1 (same frozen W8/9 metric `tools.translation_layer.word_f1`). Report token recall (matched form tokens / all source transliteration tokens), unit and sentence abstention rates, exact train sentence-form sequence repeats, source distribution, mean sentence F1 and corpus micro F1, number of missing refs, German word-count support, and deterministic SHA256 report. The fixed null baseline is `[?]` for every token. No repeated threshold selection, no target-derived German lexicon or model adaptation.
- **Integrity controls**: reject missing source blobs, missing/changed license, unexpected publisher 3,606 row census, giant/unsafe lines, unexpected extra fields, modified/linked source file, malformed original metadata, target reference appearing inside prediction, any donor/target source leakage, reference label mutation changing predictions, and target UPOS/glosses/lemmas used as generation inputs. Required negative controls mutate target reference and target explanatory annotation labels and check identical predictions but changed evaluator result.
- **Report must disclose**: The TLA source has **no physical-witness or text ID in published rows**; TLA editorial genealogy overlaps/relates to AES; W11 donor has prior exposed content; public TLA dataset and one example known. Therefore report is a **newly evaluated published corpus on a train-only lexical method, not independent source/witness-heldout, blindly adjudicated semantic translation**, and cannot earn original LING-003 2/2 without independent image→line and expert adequacy. 0 new trained neural models, official Egyptian-PC TEST unopened, project progress 34.5/100 unchanged.
