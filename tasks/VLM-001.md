## 2. Core Scientific Requirements and Boundaries

1. **Immutable Evaluation Conditions:**
   - Pre-register exact model identifiers, revisions, greedy decoding parameters (`temperature=0.0`, seed 42), and image preprocessing constraints ($\le 1024$ px longest edge, RGB).
   - Freeze zero-shot and few-shot prompt templates via cryptographic SHA-256 hashes.

2. **Quarantined Demonstration Governance & Fail-Closed Clearance:**
   - The current demonstration bank (`eval/vlm/demonstrations.yaml`) is strictly designated as `synthetic_fixture_only` with `rights_review_status: synthetic_placeholder_unreviewed`.
   - **Real few-shot inference fails closed** unless authentic image files exist on disk with valid image pixels, verified item-specific rights/provenance records, cryptographic file hashes, and documented exact/near-duplicate quarantine clearance against benchmark and training partitions.
   - Self-declared clearance booleans are rejected; genuine image evidence and independent checks are mandatory.

3. **Inference Capability & Hardware Barrier Disclosures:**
   - `OpenWeightVLMAdapter` includes a real, reproducible image-conditioned PyTorch/Transformers execution path.
   - In environments lacking dedicated NVIDIA CUDA GPUs ($\ge 16$ GB VRAM) or downloaded model weights, the adapter accurately identifies and reports the hardware/weights barrier and fails closed (`status: failed`, diagnostic error message), without fabricating synthetic outputs or initiating unapproved network API calls.

4. **Dual-Channel Metric Scoring:**
   - **Channel 1 (Official HieraticBench):** The pinned upstream TypeScript scorer (`bench/src/score.ts`) is authoritative for official benchmark scores.
   - **Channel 2 (Project-Native EVAL-001 Diagnostics):** In-house metrics are explicitly labeled using IDs from `eval/metric_contract.yaml` (`SCRIPT_ACC`, `SIGN_ACC`, `CER_V1`, `WER_V1`, `TRANSLATION_BLEU_4`, `TRANSLATION_CHRF`).
   - Local string heuristics must never be claimed or mislabeled as upstream official scores.

5. **Statistical Reporting Following EVAL-006:**
   - Confidence intervals must use at least **2,000 document-clustered bootstrap resamples** ($B=2000$) clustered by `document_id`.
   - Single or zero document clusters must report a null confidence interval (`insufficient_document_clusters`), rejecting fabricated zero-width intervals (such as `[1.0, 1.0]`).
   - Paired comparisons must pair attempts strictly across composite identities `(item_id, rung, shot_mode, sample_index)`.
   - Full denominator accounting: intention-to-test and conditional scores must be reported with explicit failure, refusal, timeout, and abstention counts.

6. **Promotion Prevention for Synthetic Fixtures:**
   - Manifests and score reports generated by `mock-vision-v1` are immutably tagged with `execution_tier: "synthetic_ci_fixture"` and `scientific_validity: "non_scientific_test_fixture"`.
   - Promotion of synthetic CI fixtures into certified scientific baseline results is strictly blocked by the CLI auditor and governance contracts.
