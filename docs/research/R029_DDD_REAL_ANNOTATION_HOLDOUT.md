# W24 — Actual published 2026 DDD annotation research, zero external outreach

Publisher: [Zenodo DDD 20553713](https://zenodo.org/records/20553713) original 2026 research-only CC BY-NC-SA. **Aim:** use genuine original 17,885 publisher annotation sample records, 504 sign/group label types, 159 images grouped into 50 physical papyri to measure label/holdout difficulty, find correct source-disjoint split, and establish honest negative/majority-class control. This is not reading genuine pixels. Never train an image classifier on an unlicensed DDD photo. No public benchmark sealed answers.

W23 [source audit](R028_DDD_PUBLISHER_RESEARCH_ROUTE.md) established real original publisher MD5 and SHA256; all source records strictly fetched and SHA verified, no raw 2 GB image set. The W24 artifact will compute original label distribution, provenance and grouping from accepted public publisher metadata. No contributor can use a public corpus with a different revision, claim synthetic values as authentic, or silently count alternate images/rotations as different physical documents.

**Gate:** production DATA-008 remains hard-disabled; this is explicitly a noncommercial research-only analysis of publisher metadata, not a model capability score or new expert-blind independently adjudicated line corpus.
