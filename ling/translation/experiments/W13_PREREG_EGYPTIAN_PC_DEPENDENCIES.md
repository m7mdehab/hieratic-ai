## Frozen narrow experimental question

Can a deterministic **train-only tag-conditioned dependency-head and relation frequency model**, operating on the officially published token forms and/or gold POS on official DEV, recover nontrivial dependencies of this *Old Egyptian* treebank at better-than-trivial baselines without target dependency labels?

1. **Train split exclusively** `egy_pc-ud-train.conllu`. Read dev only after this registration, treat all dev dependency heads and relation labels as evaluation-only. Test is sealed/not retrieved. Do not tune model or select hyperparameters using dev gold, and do not inspect official test file.
2. **Input privilege disclosed:** use **gold UPOS on development**, plus token order; this is an **oracle POS-conditioned dependency experiment**; not end-to-end POS tagging or source-image interpretation. Never access a dev HEAD/DEPREL/FEATS/LEMMA or sentence text to generate predictions. At training time, permit gold UPOS/HEAD/DEPREL because it is expressly the training partition.
3. **Frozen baseline**: choose previous token as head for all positions >1, ROOT for first token; assign most common train relation for that dependent UPOS (or `dep`); force chosen root relation `root`. This is intentionally naive.
4. **Frozen statistical method:** for each child UPOS, candidate head UPOS (including synthetic ROOT), and offset sign (left/right/root), count training instances of (UPOS-child, UPOS-head, direction, DEPREL). At dev time enumerate every token head plus ROOT, prohibit self loops, and choose candidate by (1) train log-smoothed relation frequency conditioned on UPOS pair and direction, (2) distance penalty `0.02 * abs(head_index - child_index)` for nonroot, (3) deterministic earliest-head tie break. Choose DEPREL from same train-only majority lookup; when no evidence fall back to `dep`. Require tree-structure repair in a **frozen deterministic way** to exactly one root and no cycles: choose root with largest model ROOT evidence score (ties earliest), independently predict remaining heads from non-ROOT candidates excluding self, and when a cycle exists break the cycle by routing the lowest-index member directly to selected root with its train-only label. Prefer not to attach any other token to ROOT after repair.
5. For both systems compute official word-token UAS and LAS on every dev word (non-multiword token lines), total tokens, sentence count, whether every predicted tree has exactly one ROOT and zero cycles, predicted relation inventory vs train, and error by dependent UPOS with denominators. Use absolute test population; never cherry-pick examples. **Do not equate gold-POS UAS/LAS with real parsing from unannotated hieratic.**
6. No heldout/dev feedback loop: If first result is poor, record it as negative. If technical code/tests need correction, record bug and keep frozen model objective unchanged. No claims of a new certified historical language model, no LING-003 milestone award.
7. Implement source-locked CoNLL-U loader with syntax checks: no malformed ID, duplicate token ID, out-of-range head, missing gold relation (train/dev audit only), cycles or multiple original roots; no silent dropping entire sentences; stable source/witness ID and rights attribution. Detect original tree labels / metadata provenance mismatches. In tests mutate dev labels and confirm predictions unchanged while accuracy changes.

The official DEV is exposed upon first scoring. Do not later present this specific split as untouched if methods are revised. The official test split remains unaccessed, and original experimental/report hashes must be preserved.
